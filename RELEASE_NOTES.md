# 🎉 TalkTrace AI neo — Streaming & Multi-Coding Release

> Big one. Two new features, several papercuts gone, codebase cleaner.

---

## ✨ What's new

- **Live coding view** — codings appear in the table as the LLM produces them
- **Multi-coding** — multiple codes per utterance when more than one fits
- **Codebook priority hierarchy** — you decide which code wins
- **Free history reloads** — restoring a saved session no longer costs money

## 🔧 Plus

- Smarter prompts, better defaults
- Tooltips that read like sentences instead of towers
- A streaming toggle, a Cloud-Hinweis, and assorted polish
- The async refactor that finally made streaming feel right
